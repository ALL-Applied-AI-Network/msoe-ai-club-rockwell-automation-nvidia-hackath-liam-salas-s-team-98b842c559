# Writing for this team

- Simple English, close to ASD-STE100. Short sentences. Active voice. One idea per sentence.
- Define jargon on first use, or link `docs/glossary.md`.
- Explain the why. The team are students who want to learn.
- Never invent facts. Mark each claim: measured / read in a file / guess.
  "I do not know" is a good answer.
- Be critical. Name the weak points of an idea.
- Keep `docs/plan.md` and the team pipeline doc in step when the plan changes.
