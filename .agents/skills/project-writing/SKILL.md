# Project writing

## Inputs
Audience, requested output, source files and current evidence.
Use the [docs index](../../../docs/README.md).

## Workflow
1. Lead with the problem/current state and explain why. Define unfamiliar terms.
2. Separate measurements, decisions, proposals and unchecked claims; trace numbers to sources.
3. Keep detailed facts in one document and link to them.
4. For status/review prose, include verification, limits and the next action.
   Resolve dated source conflicts or state them explicitly.

## Output and validation
Concise prose with sources; check paths/commands and run python scripts/check_agent_docs.py.

## Limits
Do not invent results or promote estimates to measurements. Writing does not authorize
sending or external edits. Shared writing policy lives in [AGENTS.md](../../../AGENTS.md).
