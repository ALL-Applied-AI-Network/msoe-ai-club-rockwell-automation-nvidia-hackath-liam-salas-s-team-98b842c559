# Procedural tank station asset

`tank_station.usda` is an original, self-contained ASCII USD asset generated by
`src/fluidmix/tank_station.py`. It includes four vessels, separate liquid meshes,
plumbing, supports, small geometry labels, materials, camera and lighting. It has no
external asset dependencies and contains a static snapshot of the illustrative initial
levels. T300 is empty and inactive. The full animation is generated on demand.

Regenerate without overwriting the reviewed copy:

```sh
python scripts/build_tank_station.py --out outputs/tanks/rebuild \
  --snapshot outputs/tanks/rebuild/snapshot.usda
cmp assets/tanks/tank_station.usda outputs/tanks/rebuild/snapshot.usda
```

Tested with usd-core 26.11 on macOS; rendered with Isaac Sim 6.0.1 / USD 26.8 on
Spark GB10. The source is texture-free and portable across the two checked versions.
Different USD versions may change text serialization.

The geometry references the layout in Dataset 2's
`tank_level_20260923_194717_665803.jpg`. The original image stays outside Git.
`reference-landmarks.json` records its hash and nine approximate manual landmarks.
These points were used to fit the camera; their residual is **not held-out accuracy**.
The reference image is a geometry/camera input and must not later be called an independent
validation image. Absolute scale, dimensions, wall thickness, optics and placement are
unmeasured. No original organizer USD or image is embedded in this asset.

See [usage and data contract](../../docs/tank-station.md) for animation, labels,
render validation, provenance and readiness limits. Use `set_volumes` in an override
layer for the drainage model's outputs. The default levels are not real recipes.
