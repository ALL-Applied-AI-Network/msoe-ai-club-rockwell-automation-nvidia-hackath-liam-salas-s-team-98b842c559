# Glossary
- **Absorbance (A):** how much light a liquid removes, on a log scale. A = 1 lets 10% through.
- **Beer-Lambert law:** A = epsilon * concentration * path length. Absorbances of dyes add.
- **Carryover:** old fluid left in the shared path that ends up in the next vial.
- **Changeover:** the switch from one recipe to the next.
- **dE (Delta E, CIE76):** distance between two colors in Lab space. ~2 just visible, >10 clear.
- **I0:** light seen through clear water. The reference for absorbance.
- **Lab:** a color space made so distances match how people see differences.
- **Linear RGB:** pixel values before gamma. Light adds and multiplies correctly here.
- **sRGB:** normal image pixel values (0-255), with gamma.
- **Digital twin:** a 3D model of the line (USD) used to render synthetic training images.
- **USD:** Universal Scene Description, the 3D file format of the twin.
- **Cosmos Reason:** NVIDIA vision-language model; we use it to write operator messages.
